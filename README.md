# Aero Makers at Georgia Tech

Club website for Aero Makers @ GT.

**Live site:** https://aeromakersgt.github.io/

## How to edit the website

You do this on your computer. The live site only changes after you click **Deploy**.

### 1. Open the editor

1. Install [Python](https://www.python.org/downloads/) if it is not already installed. Check **Add Python to PATH** during setup.
2. Open the `AMGT Website` folder.
3. Double-click **Edit Website.bat**.
4. Leave the black window open. Closing it turns the editor off.
5. Your browser should open the site with a navy **Website Editor** bar at the top.

If the browser does not open, copy the address printed in the black window (usually http://127.0.0.1:8765/index.html).

### 2. Make your changes

- Use the normal site menu to go to Home, About, Events, Equipment, Sponsors, or Contact.
- Click a gold-outlined title, description, photo, or card.
- Type in the side panel. The page updates as you type.
- On Events, Equipment, Sponsors, and About you can add or remove items (events, photos, sponsors, board members).

### 3. Revert, Save, or Deploy

| Button | What it does |
| --- | --- |
| **Revert** | Throws away edits you have not saved yet and restores the last save. |
| **Save** | Writes the changes onto this computer. The live website is not updated yet. |
| **Deploy** | Saves, then uploads the site to GitHub. The public site updates in a minute or two. |

You need GitHub access to the `aeromakersgt.github.io` repo for **Deploy** to work.

## Notes

- Python only runs on your computer. It is not required for visitors.
- Photos you add are copied into `images/uploads/`.
- If Deploy fails, you are probably not signed in to a GitHub account that can write to the club repo.
